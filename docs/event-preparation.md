# เตรียมงานและส่งของก่อนวันเปิดงาน

Migration: `0187_event_preparation_and_tank_register.sql`

ตัวอย่าง: งานเปิด 21–25 ก.ย. ร้านบางส่วนรับถังและน้ำแข็งวันที่ 20 ก.ย.

1. เปิดงานอีเวนต์ → **เตรียมงาน / ส่งล่วงหน้า** → **เลือกร้านที่รับของก่อนวันเปิดงาน**
2. เลือกวันที่ 20 ก.ย. และเฉพาะร้านที่ต้องรับของ แล้วบันทึก เปิดใช้ได้ทั้งงานฉบับร่างและงานเผยแพร่แล้ว แต่ต้องเผยแพร่ก่อนส่งจริง
3. ในเมนูบันทึกส่งน้ำแข็ง เลือกวันที่ส่งจริงและอีเวนต์นี้ รีเฟรชรอบส่งหากเปิดไว้ก่อนเพิ่มร้านรับล่วงหน้า ราคาน้ำแข็งต้องครอบคลุมวันเตรียมงาน
4. ใช้ **บันทึกตั้งถัง / รับคืนถัง** บันทึกจำนวนที่ส่งจริง ข้อมูลถังจาก Excel เป็นข้อความประกอบ จึงไม่ถูกนับเป็นรายการส่งมอบอัตโนมัติ

วันจัดงานและวันเข้าร่วมเดิมไม่เปลี่ยน `preparation_start_date` ขยายเฉพาะช่วงปฏิบัติงานของร้านที่เลือก ร้านอื่นยังเริ่มในวันเดิม การขยายวันรองรับ sync, รายชื่อร้าน, POS, บันทึกส่งน้ำแข็ง และ settlement context พร้อมกัน

วันเริ่มค่าเช่าถังเป็นวันเปิดงาน หากส่งหลังเปิดงานจะใช้วันส่งมอบ เก็บราคาเช่าจาก configuration ที่ถูกตรึงไว้ตอนเผยแพร่ในทะเบียนถัง **ทะเบียนนี้ยังไม่สร้างบิลค่าเช่าหรือรายการรับเงินในระบบบัญชี** ยอดน้ำแข็งยังลงบัญชีผ่านระบบเดิมตามวันที่ส่งจริง

รายการถังเก็บวันจริง จำนวน ผู้บันทึก และหมายเหตุ ส่งเพิ่มและคืนบางส่วนได้ รับคืนหลังจบหรือยกเลิกงานได้ แต่คืนเกินยอดถังที่ร้านถือในวันนั้นไม่ได้ จำกัดสิทธิ์จัดการให้ admin และ round lead และใช้ request ID ป้องกันบันทึกซ้ำ

วันเตรียมงานที่บันทึกแล้วเลื่อนให้เร็วขึ้นได้ แต่ลบหรือเลื่อนให้ช้าลงไม่ได้ เพื่อไม่ทำให้ประวัติส่งและยอดค้างอยู่นอกช่วงบริการ
