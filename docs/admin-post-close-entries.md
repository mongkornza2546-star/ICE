# รายการของแอดมินหลังปิดยอด

Migration `0254_admin_post_close_entries.sql` รองรับการเพิ่มรายการ และ `0255_admin_post_close_cancellations.sql` เพิ่มการยกเลิก ต้องลงตามลำดับก่อน frontend รุ่นนี้ หากลง 0254 แล้วให้รันเฉพาะ 0255 ต่อได้

- แอดมินที่ยังใช้งานอยู่เลือกงานที่ปิดแล้วในวันนี้หรือวันก่อนหน้าและเพิ่มรายการส่งของได้ ทั้งร้านประจำและปลายทางอีเวนต์ที่ยังมีสิทธิ์ดำเนินการ งานที่ยกเลิกและวันที่อนาคตยังถูกปฏิเสธ
- การส่งหลังปิดสต๊อกเป็นการลงรายการที่ตกหล่น จึงไม่ใช้ยอดพร้อมขายที่ถูกตั้งเป็นศูนย์หลังปิดวันเป็นเพดาน ใช้ต้นทางรถบรรทุกเดิม ราคา/VAT/เครดิต และการตรวจข้อมูลเดิม วันเปิดยังตรวจยอดรถและยอดรวมตามเดิม
- แอดมินเข้าคิวเก็บเงินของวันที่ปิดแล้วได้และเลือกวันที่รับเงินย้อนหลังได้ เมื่อเข้าวันย้อนหลังโดยตรง วันที่รับเงินเริ่มต้นเป็นวันที่เลือก เก็บเวลาที่ลงข้อมูลจริงแยกจากวันที่รับเงิน
- ใช้ collection run เดิมแม้ปิดแล้ว ไม่เปิดวันเก่ากลับขึ้นมา หากวันปิดสต๊อกไม่มี run จะสร้างบริบทที่มีสถานะปิดเพื่อรองรับการลงรายการของแอดมิน
- แอดมินยกเลิกใบส่งที่ยังไม่รับชำระและยกเลิกใบรับเงินที่บันทึกผิดหลังปิดยอดได้ โดยต้องระบุเหตุผล หากใบส่งรับเงินแล้ว ต้องยกเลิกใบรับเงินที่ผิดก่อน เงื่อนไขรายการล่าสุด ใบวางบิล และรายการที่ผูกกับการคืนเงินยังใช้ตามเดิม
- การแก้ยอด/วันที่/ผู้รับเงินโดยตรง การลบรายการเงินสด และการแก้ stock movement ของวันปิดยังถูกล็อกไว้
- ตรวจสิทธิ์ที่ฐานข้อมูลทุกครั้ง ไม่อาศัยการซ่อน/เปิดปุ่มอย่างเดียว พนักงานและหัวหน้ารอบไม่มีสิทธิ์ข้ามการปิดวัน

## ประวัติและยอดปิด

ใบส่งและใบรับเงินใหม่เข้า ledger และรายงานตามวันที่ธุรกิจตามปกติ ยอดปิดสต๊อก ยอดตรวจนับเงินสด และรายการส่งมอบเงินเดิมเป็นหลักฐาน ณ เวลาปิด จึงไม่เขียนทับหรือถือว่าเงินที่ลงเพิ่มได้ถูกส่งมอบไปแล้ว ยอดในรายงานปัจจุบันอาจต่างจาก snapshot เดิมตามรายการเพิ่มหลังปิดวัน

Audit `admin_post_close_entry` เก็บผู้ลงรายการ วันธุรกิจ เวลาลงรายการจริง และ ID ของใบส่ง/ใบรับเงินเพื่อไล่ตรวจส่วนต่าง การกดซ้ำใช้ idempotency เดิมและไม่เพิ่มยอดหรือ audit ซ้ำ ยอดพร้อมใช้ของวันปิดยังเป็นศูนย์

การยกเลิกหลังปิดยอดเพิ่ม audit `admin_post_close_cancelled` พร้อมข้อมูลก่อน/หลัง ผู้ยกเลิก และเหตุผล ยกเลิกใบรับเงินแล้วหนี้จะกลับมาคำนวณตามบิลเดิม ยกเลิกใบส่งแล้วเอายอดขายและจำนวนส่งของรายการนั้นออกจาก ledger แต่ไม่เปลี่ยน snapshot การปิดยอดหรือบันทึกส่งมอบเงินเดิม
