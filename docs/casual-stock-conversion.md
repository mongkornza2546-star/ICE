# ลูกค้าขาจรในบัญชีและสต๊อก

ตารางรายวันเพิ่มแถวลูกค้าขาจรเหนือร้านค้า แสดงน้ำแข็งออกแต่ละชนิด ยอดขาย รับเงินจริง คืนเงิน และเงินสุทธิ แถวนี้รวมทุกจุดถือครองในช่วงวันที่เลือก ไม่ขึ้นกับตัวกรองร้าน/โซน และไม่รวมซ้ำในยอดของกลุ่มร้าน ไฟล์ Excel มีชีตลูกค้าขาจรหนึ่งชีตแม้รายงานร้านมีหลายหน้า

รายการที่ระบุจำนวนหักสต๊อกตามจำนวนเดิม รวมรายการแจกฟรี รายการจ่ายทันทีที่ไม่ระบุจำนวนสะสมยอดขายหลังทอน แยกตามวันบริการ จุดถือครอง และชนิดน้ำแข็ง ทุกครั้งที่ครบราคากลางต่อถุงนับออก 1 ถุง เศษยอดไม่ยกข้ามวันหรือจุดถือครอง เช่น ราคา 100 บาท ยอด 60 + 50 บาท นับออก 1 ถุง เหลือเศษ 10 บาท รายการที่ระบุจำนวนจะไม่เข้ายอดสะสมอีก

ระบบเก็บราคากลางที่ใช้ต่อวัน/จุดถือครอง/ชนิดไว้ถาวร การเปลี่ยนราคาภายหลังไม่เปลี่ยนจำนวนย้อนหลัง การบันทึกและยกเลิกใช้ล็อกวันบริการเดียวกับสต๊อกเดิม คำขอซ้ำไม่สะสมซ้ำ รายการที่ทำให้จำนวนถุงเกินสต๊อกถูกปฏิเสธทั้งรายการ การยกเลิกรายการขายยังต้องยืนยันคืนเงินเต็มจำนวน แล้วคำนวณจำนวนถุงจากรายการที่เหลือใหม่

สต๊อกพนักงาน สต๊อกรวม สรุปเทียบยอด และเอกสาร SALE ใช้การแปลงเดียวกัน จำนวนออกในเอกสาร SALE คือจำนวนถุงที่ยอดสะสมครบในรายการนั้น สำเนาใบรับเงินเดิมไม่ถูกแก้ไข รายการแจกที่ไม่ระบุจำนวนและเศษยอดยังต้องตรวจนับจริง เพราะจำนวนเงินจริงไม่สามารถบอกปริมาณตักจริงได้ละเอียดกว่ากติกาที่กำหนด

การเปิดใช้ต้องลง migration 0179 และ 0180 ตามลำดับพร้อมหน้าเว็บรุ่นนี้ โดย migration 0179 จะรวมรายการแบ่งขายเดิมเฉพาะวันที่ยังไม่ปิดสต๊อกและมีราคากลางครอบคลุมวันบริการ อาจทำให้ยอดควรเหลือของวันที่เปิดอยู่ลดลงตามยอดขายที่เดิมยังไม่หัก วันที่ปิดแล้วหรือไม่มีราคากลางจะไม่ถูกแปลงย้อนหลัง และแสดงยอดยังไม่แปลงในตาราง/Excel ให้ตรวจสอบ

ยอดขายในหน้าปิดสต๊อกรวมรวมจำนวนขาจรที่ระบุไว้ (รวมแจกฟรี) และจำนวนถุงที่แปลงจากยอดเงิน เพื่ออธิบายยอดคงเหลือตามระบบให้ตรงกับสรุปเทียบยอด เมื่อยกเลิกรายการ ยอดขายและยอดคงเหลือคำนวณใหม่พร้อมกัน

ตรวจด้วยฐานข้อมูล PGlite ที่รันฟังก์ชัน SQL จริง: ครบเกณฑ์ รับคำขอซ้ำ ยกเลิก เปลี่ยนราคา ขายเกินสต๊อก ไม่มีราคา แยกวัน/ชนิด/จุดถือครอง ไม่หักรายการระบุจำนวนซ้ำ และสิทธิ์อ่านรายงาน รวมถึงยอดขายที่หน้าปิดสต๊อกและยอดนับที่บันทึกหลังปิดวัน ตรวจ UI และ Excel กรณีมีเฉพาะขาจรโดยไม่มีร้านในรายงานด้วย
